# ♻️ EcoSmartBin – Sistema IoT para Reciclaje Inteligente & Microservicios

**EcoSmartBin** es una solución distribuida e inteligente orientada a la gestión y clasificación eficiente de residuos reciclables mediante IoT, Inteligencia Artificial y arquitecturas escalables en la nube.

### 🛠️ Características Principales & Mi Contribución

* **Diseño de Microservicios & Backend:** Desarrollo de servicios REST en **Java (Spring Boot)** para el procesamiento de métricas, registro de usuarios e histórico de reciclaje.
* **Modelado & Persistencia de Datos:** Estructuración de esquemas relacionales en **Supabase (PostgreSQL)** para lecturas en tiempo real y persistencia transaccional.
* **Infraestructura Cloud & DevOps:** Contenedorización con **Docker** y despliegue automático en **Google Cloud Platform (GCP)** mediante pipelines de **CI/CD**.
* **Captura de Imágenes & Algoritmos:** Configuración de placas **ESP32-CAM**, procesamiento visual con IA para la clasificación de residuos y algoritmos de selección de líder (*Leader Election*).
* **Cliente Móvil:** Integración con la aplicación móvil en **Flutter** para la visualización del estado de los contenedores en tiempo real.

---

### 🧰 Tech Stack

* **Backend:** Java (Spring Boot), REST APIs.
* **Base de Datos:** PostgreSQL / Supabase.
* **Cloud & DevOps:** Google Cloud Platform (GCP), Docker, CI/CD, Git.
* **IoT & Hardware:** ESP32-CAM, C/C++ (Arduino IDE).
* **Frontend Móvil:** Flutter (Dart).
